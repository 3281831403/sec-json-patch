配置中心接受外部提交的补丁，攻击者用一个路径穿越写法改掉了本不该暴露的开关，而且失败回滚后仍留着改动：越权路径能进入文档，补丁中途出错时已改的键也不会复原。修复后必须满足：补丁原子应用，任何一步失败则整份不生效；路径解析支持转义序列与数组下标；数组追加与插入的下标语义必须区分；删除不存在的路径必须失败；测试操作不得改变文档；数组下标越界必须拒绝。不变量：对同一文档重复应用幂等补丁，结果必须相同；任何应用失败的文档必须与原文档深度相等。
